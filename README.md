# Cartoon Tetris

This project implements a simple cartoon-style Tetris game playable directly in the browser. It supports account login with a username and password and keeps a persistent high score leaderboard using `localStorage`.

## Running

Simply open `index.html` in any modern web browser. No additional dependencies or server setup is required.

## Controls

- **Arrow Left/Right** – move the piece horizontally
- **Arrow Up** – rotate
- **Arrow Down** – soft drop
- **Space** – hard drop

After logging in, your best score will be tracked and added to the leaderboard. You can log out at any time using the button on the page.
